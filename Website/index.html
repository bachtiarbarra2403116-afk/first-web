Fate/Grand Order

LASENGLE / TYPE-MOON

Fate/Grand Order adalah game RPG gacha seluler dari seri Fate untuk Android dan iOS yang dikembangkan oleh LASENGLE (sebelumnya DELIGHTWORKS), diterbitkan oleh Aniplex, dan dilisensikan oleh TYPE-MOON. Awalnya dirilis di Jepang pada 2015. Game ini adalah RPG berbasis giliran (turn-based) dengan segmen cerita bergaya visual novel.

Sampai saat ini, F/GO masih eksis dan mampu bersaing dengan game tipe gacha lainnya. Kekuatannya selama 11 tahun terus didukung oleh komunitas yang besar. Terlepas dari kejayaannya tersebut, F/GO dinilai playernya sebagai game yang cukup "pelit". Bagaimana tidak, untuk mendapatkan satu karakter bintang 5 baru dijamin pada pull ke-330.

Berikut adalah informasi mengenai akun saya:

  • Nickname: tiarrr
  • Level: 140
  • ID: 283,164,915

Akun ini berada pada server JP sehingga hanya bisa berteman pada akun dengan server yang sama. Hampir sulit dipercaya di game yang memiliki pity hingga menyentuh 330 pull ini, akun saya diberikan banyak karakter limited.
